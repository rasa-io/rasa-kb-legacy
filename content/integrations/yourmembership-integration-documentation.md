Here are the steps to integrate with YourMembership.

1. Login to dashboard.rasa.io
2. Navigate to Settings > Integrations > YourMembership  
   ![]()![a5452bc38eeaf39608d7e6ce3cd3ef59321b67c5815eb6cfa500599e61471cf0](https://22539073.fs1.hubspotusercontent-na1.net/hubfs/22539073/a5452bc38eeaf39608d7e6ce3cd3ef59321b67c5815eb6cfa500599e61471cf0.png)
3. Login to your YM account to find the above-required API configurations. For ClientID, you will navigate to Content & Settings > General Settings > API Configuration.

![]()![22f5c825112d524f9a6c49405deb5dd757a3cbfd03ec5f17dcf3bab6f3c6535f](https://22539073.fs1.hubspotusercontent-na1.net/hubfs/22539073/22f5c825112d524f9a6c49405deb5dd757a3cbfd03ec5f17dcf3bab6f3c6535f.png)

4. For API Key and API Password, navigate to Content & Settings > Admin Accounts > Administrators > API Accounts.

![ac1fc0384c5ef66b6eefc3c30c52f5849445251d9ba352441bdb1cf6e69b5001](https://22539073.fs1.hubspotusercontent-na1.net/hubfs/22539073/ac1fc0384c5ef66b6eefc3c30c52f5849445251d9ba352441bdb1cf6e69b5001.png)

![]()5. For Member Type, navigate to Content & Settings > Member Settings > Member Types and copy the TypeCode for whichever Member Type you want to sync.

![]()![def05abd15efaf25be4bccabad5855ebaa9bf6a6cab691a9ce3af93bf98bda6e](https://22539073.fs1.hubspotusercontent-na1.net/hubfs/22539073/def05abd15efaf25be4bccabad5855ebaa9bf6a6cab691a9ce3af93bf98bda6e.png)
