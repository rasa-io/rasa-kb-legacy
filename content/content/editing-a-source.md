You have the ability to edit a source by clicking the 3 dots next to the source on the [Sources page](https://dashboard.rasa.io/content/sources) and choosing the option that says Edit.

![mceclip0 (5)](https://22539073.fs1.hubspotusercontent-na1.net/hubfs/22539073/mceclip0%20(5).png)

![]()The Edit Source page gives you the option to rename the source. It also provides allows you to edit the filters that have been applied to a given source. If you need to change the actual URL or handle of the source, you will need to Archive it and re-add it.

![mceclip1 (4)](https://22539073.fs1.hubspotusercontent-na1.net/hubfs/22539073/mceclip1%20(4).png)

\*Note - to archive (which is the equivalent of delete) a source, you will need to click the same three dots that allow you to edit and choose the option that says archive.
