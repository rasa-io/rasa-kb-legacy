We do our best to make sure all of our templates are designed as carefully and cleanly as possible but since Outlook renders email HTML using Microsoft Word, the display does not always look as neat as it would in other email platforms. This is because Microsoft Word is designed for print so when Outlook attempts to render email HTML, it displays it as it would in Print Preview.

Our templates do take this into consideration and we use specific coding techniques to get as close as we possibly can to a uniform design across all email platforms but there can be discrepancies across all providers. If you ever see an element of your Template on the [Design](https://dashboard.rasa.io/design) and/or [Preview](https://dashboard.rasa.io/preview) page that does not match up with your email rendering, please contact [support@rasa.io](mailto:support@rasa.io) and we would be happy to assist you.

**Outlook Desktop Compatibility with WebP Images:** When using the older versions of Outlook Desktop may encounter issues with displaying WebP file-type images.

To address compatibility issues with WebP images in Outlook Desktop, we recommend users refer to resources such as [Can I Email](https://www.caniemail.com/features/image-webp/) for insights into email client compatibility with WebP images. Also, simply upgrading to the latest version of Outlook Desktop will improve compatibility. See the image below for where and how to do this!
