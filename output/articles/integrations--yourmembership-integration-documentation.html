Here are the steps to integrate with YourMembership.

  1. Login to dashboard.rasa.io
  2. Navigate to Settings > Integrations > YourMembership
  3. Login to your YM account to find the above-required API configurations. For ClientID, you will navigate to Content & Settings > General Settings > API Configuration.

  1. For API Key and API Password, navigate to Content & Settings > Admin Accounts > Administrators > API Accounts.

5. For Member Type, navigate to Content & Settings > Member Settings > Member Types and copy the TypeCode for whichever Member Type you want to sync.
